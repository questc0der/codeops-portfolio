# Habesha Eatery Mini-Site

This is a simple two-page site for a fictional restaurant in Bole, Addis Ababa.

## How to open

- Open `index.html` for reservations.
- Open `contact.html` for the contact page.

## Accessibility features

- real labels on all form controls
- semantic landmarks like `header`, `nav`, `main`, `section`, and `footer`
- keyboard-friendly navigation links
- table captions and column headers with `scope`
- meaningful image alt text
- title text for the map iframe
