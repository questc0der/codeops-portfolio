# Ethio Dashboard Mini-Project

This page is a simple dashboard layout inspired by an Ethiopian online account screen.

## Grid

- `.app` uses `grid-template-areas`
- header
- sidebar
- main
- footer
- the layout collapses to one column on mobile

## Flexbox

- header row
- toolbar row
- stats row

## Responsive grid

- `.cards` uses `repeat(auto-fit, minmax(220px, 1fr))`

## Sticky element

- the header stays sticky at the top

## Absolute positioning

- the `ETB Sale` style badge is pinned to the card corner
